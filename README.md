# PHARMACY_MANAGEMENT_SYSTEM-PYTHON
A simple Pharmacy Management System built using Python and Tkinter with file-based storage to manage medicines, inventory, and basic CRUD operations.

Pharmacy Management System (Python)
📌 Overview

This Pharmacy Management System is a desktop-based GUI application developed using Python and Tkinter.
It is designed to perform basic pharmacy operations such as adding, updating, deleting, searching, and viewing medicine records using a simple file-based database.

The project focuses on understanding GUI development, file handling, and CRUD operations in Python.

🖥️ Application Type

Desktop Application

GUI-based (Tkinter)

File-based storage system

🚀 Features

➕ Add new medicine items

🗑️ Delete existing items

✏️ Update item details

🔍 Search item by name

⏮️ View first record

▶️ View next record

⏪ View previous record

⏭️ View last record

🧹 Clear input fields

📁 Persistent storage using text file

🛠️ Tech Stack

Language: Python

GUI Library: Tkinter

Storage: Text file (database_proj)

IDE: PyCharm / VS Code

⚙️ How the System Works

User enters medicine details:

Item Name

Price

Quantity

Category

Discount

Data is stored in a text file (database_proj)

User can:

Navigate through records

Search items by name

Update or delete existing records

Data remains saved even after closing the application

▶️ How to Run the Project

Make sure Python is installed

Clone the repository

Run the file:

python project.py


The GUI window will open automatically
